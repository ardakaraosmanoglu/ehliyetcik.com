---
title: No semicolons in user-visible text
type: decision
tags: [copy, style, appstore]
---
User rule: user-visible Turkish text (app UI in `src/`, `site/` pages, App Store texts in `docs/appstore/metadata.md`) must not contain semicolons. Use a comma or a period instead. Exception: booklet content in `src/data/questions.json` stays verbatim (see [[app-store-risk-5-2-4-2]]). Code syntax is not affected.
